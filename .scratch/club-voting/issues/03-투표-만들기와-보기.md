# 03: 투표 만들기, 그리고 투표 화면 보기

**What to build:** 운영자가 질문, 선택지, 마감 시각(한국 시간)을 입력해 투표를 만들면, 그 투표의 고유 링크 화면으로 이동해 링크를 복사할 수 있다. 누구든 그 링크를 열면 질문과 선택지를 입력한 순서대로 본다. 없는 링크는 "투표를 찾을 수 없다"는 화면을 보여준다. 스펙의 "투표 만들기 검증", "시간대", User Story 9, 17, 32~41, 46.

**Blocked by:** 02 (운영자 로그인과 로그아웃)

**Status:** ready-for-agent

- [ ] 투표 모듈의 "투표 만들기"가 질문(공백 제거 후 1~200자), 선택지(공백 제거 후 각 1~100자, 2~10개, 중복 없음), 마감 시각(현재 시각보다 뒤)을 검증하고 실패 사유를 판별 가능한 값으로 돌려준다
- [ ] 공백만 다른 선택지는 중복으로 거절된다
- [ ] 투표 모듈의 "투표 하나 보기"가 질문, 입력 순서대로의 선택지, 마감 시각을 돌려주고, 없는 투표는 "찾을 수 없음"을 돌려준다
- [ ] 운영자 전용 투표 만들기 화면에서 선택지 입력 칸을 추가/삭제할 수 있고, 검증 실패 사유가 화면에 안내된다
- [ ] 로그인하지 않은 요청이 만들기 동작을 직접 호출하면 서버에서 거절된다
- [ ] 마감 시각은 한국 시간(Asia/Seoul)으로 입력받아 해석해 저장하고, 화면에도 한국 시간으로 보여준다
- [ ] 만든 뒤 새 투표 화면으로 이동하고, 고유 링크를 복사할 수 있다
- [ ] 질문·선택지를 수정하는 동작은 존재하지 않는다
- [ ] 만들기 검증 시나리오(선택지 1개/11개, 공백만 다른 중복, 빈 질문, 과거 마감 시각)와 보기/찾을 수 없음 테스트가 투표 모듈 경계에서 통과한다
