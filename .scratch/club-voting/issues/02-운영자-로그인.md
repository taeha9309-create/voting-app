# 02: 운영자 로그인과 로그아웃

**What to build:** 운영자가 공용 비밀번호로 로그인하고 로그아웃할 수 있다. 로그인하면 한동안(예: 7일) 다시 입력하지 않아도 되고, 이후 티켓의 운영자 전용 동작이 서버에서 운영자 세션을 확인할 수 있는 도구가 생긴다. 스펙의 "운영자 세션", User Story 26~29, 31.

**Blocked by:** 01 (기반 준비)

**Status:** ready-for-agent

- [ ] 투표 모듈의 "운영자 비밀번호 확인하기"가 `ADMIN_PASSWORD`와 상수 시간으로 비교해 맞음/틀림을 돌려준다
- [ ] 운영자 로그인 화면에 비밀번호 입력 칸 하나가 있고, 맞으면 로그인되어 첫 화면으로 가며, 틀리면 틀렸다는 안내가 나온다
- [ ] 로그인하면 `SESSION_SECRET`으로 서명된 `httpOnly` 세션 쿠키가 발급되고 만료가 있다
- [ ] 로그아웃하면 세션 쿠키가 지워진다
- [ ] 서버 쪽에서 "지금 요청이 운영자인가"를 판단하는 도구가 있고, 위조되었거나 만료된 쿠키는 운영자로 인정하지 않는다
- [ ] 비밀번호 확인 테스트(맞음/틀림/빈 값)가 투표 모듈 경계에서 통과한다
