# 04: 표 던지기, 그리고 표를 던진 뒤 결과 보기

**What to build:** 동아리원이 로그인 없이 투표 화면에서 선택지 하나를 골라 표를 던지면, 곧바로 내 선택과 결과를 본다. 한 브라우저는 한 투표에 한 표만 던질 수 있고 바꿀 수 없다. 표를 던지기 전에는 결과를 볼 수 없다. ADR 0001과 스펙의 "동아리원 식별", "결과 공개", "결과 내용", "한 표 보장", User Story 8, 10~13, 16, 18, 19, 21~25, 50.

**Blocked by:** 03 (투표 만들기, 그리고 투표 화면 보기)

**Status:** ready-for-agent

- [ ] 동아리원 식별 쿠키가 없는 브라우저가 처음 표를 던질 때 무작위 UUID가 `httpOnly` 쿠키로 오래(예: 1년) 발급된다. 앱 전체에 하나다
- [ ] 투표 모듈의 "표 던지기"가 성공, 또는 실패 사유(투표 없음 / 이미 표를 던짐 / 이 투표의 선택지가 아님)를 돌려준다
- [ ] 같은 동아리원의 두 번째 표는 거절되고, 동시에 두 번 눌러도 DB 유일 제약으로 하나만 들어간다
- [ ] 선택지를 고르지 않고 제출하면 선택하라는 안내가 나온다
- [ ] "투표 하나 보기"가 이 동아리원이 고른 선택지를 돌려주고, 표를 던진 뒤에만 결과를 포함한다. 표를 던지기 전에는 응답에 결과가 아예 없다
- [ ] 결과에는 선택지마다 표 수와 정수 % 비율, 전체 표 수, 가장 많이 받은 선택지들(동점이면 모두)이 있고, 화면에 막대로 보인다
- [ ] 이미 표를 던진 투표에 다시 들어가면 내 선택과 결과가 보이고, 다시 던지는 입력은 없다
- [ ] 운영자도 자기 브라우저로 표를 던질 수 있다
- [ ] 한 표 보장, 다른 투표의 선택지 거절, 결과 포함/미포함, 동점 강조, 전체 0표일 때 강조 없음 테스트가 투표 모듈 경계에서 통과한다
