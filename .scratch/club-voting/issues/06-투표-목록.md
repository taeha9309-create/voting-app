# 06: 첫 화면 투표 목록

**What to build:** 첫 화면에서 누구나 투표 목록을 본다. 진행 중인 투표가 위, 마감된 투표가 아래에 있고, 각 항목에서 질문과 마감 시각(한국 시간)과 내가 이미 표를 던졌는지를 알 수 있으며, 눌러서 투표 화면으로 들어간다. 운영자에게는 "투표 만들기"와 로그아웃이 보인다. 스펙의 "목록 정렬", "화면", User Story 1~7, 30.

**Blocked by:** 05 (자동 마감과 결과 공개 규칙 완성)

**Status:** ready-for-agent

- [ ] 투표 모듈의 "투표 목록"이 진행 중 목록과 마감 목록을 따로 돌려주고, 각 항목에 질문, 마감 시각, 이 동아리원이 표를 던졌는지가 있다
- [ ] 진행 중 목록은 마감 시각이 이른 순서, 마감 목록은 마감 시각이 늦은 순서다
- [ ] 첫 화면이 Create Next App 기본 페이지 대신 투표 목록을 보여준다
- [ ] 투표가 하나도 없으면 "아직 투표가 없다"는 안내가 나온다
- [ ] 운영자로 로그인한 상태에서만 "투표 만들기" 진입점과 로그아웃이 보이고, 로그인하지 않은 사람에게는 운영자 로그인으로 가는 눈에 띄지 않는 길만 있다
- [ ] 모든 화면 하단(푸터)에 만든 사람 이름이 보인다
- [ ] 목록 정렬, 진행 중/마감 구분, 표 던짐 표시 테스트가 투표 모듈 경계에서 통과한다
