# 07: 마감 시각 바꾸기

**What to build:** 운영자가 마감 전인 투표의 마감 시각을 앞당기거나 늦출 수 있다. 새 마감 시각은 미래여야 하고, 이미 마감된 투표는 바꿀 수 없다. 이미 들어온 표는 그대로 유지된다. 스펙의 "마감 시각 바꾸기", User Story 43~45.

**Blocked by:** 05 (자동 마감과 결과 공개 규칙 완성)

**Status:** ready-for-agent

- [ ] 투표 모듈의 "마감 시각 바꾸기"가 성공, 또는 실패 사유(투표 없음 / 이미 마감됨 / 새 마감 시각이 과거임)를 돌려준다
- [ ] 마감 전인 투표의 운영자 화면에 마감 시각 바꾸기가 있고, 한국 시간으로 입력받는다. 마감된 투표에는 보이지 않는다
- [ ] 로그인하지 않은 요청이 이 동작을 직접 호출하면 서버에서 거절된다
- [ ] 바꾼 뒤에도 기존 표와 결과가 그대로 남는다
- [ ] 마감 전 앞당기기/늦추기 허용, 마감 뒤 거절, 과거 시각 거절, 바꾼 뒤 표 보존 테스트가 투표 모듈 경계에서 통과한다
