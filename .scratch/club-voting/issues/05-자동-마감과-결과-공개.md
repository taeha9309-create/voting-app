# 05: 자동 마감과 결과 공개 규칙 완성

**What to build:** 마감 시각이 지나면 투표는 저절로 마감되어 표를 받지 않고 "마감되었다"는 안내를 보여준다. 마감된 투표의 결과는 표를 던지지 않은 사람도 누구나 본다. 운영자는 마감 전이든 표를 던지지 않았든 언제든 결과를 본다. 스펙의 "마감 여부", "결과 공개", User Story 14, 15, 20, 42.

**Blocked by:** 04 (표 던지기, 그리고 표를 던진 뒤 결과 보기)

**Status:** ready-for-agent

- [ ] 마감 여부는 저장하지 않고, 현재 시각이 마감 시각 이상인지로 판단한다
- [ ] "표 던지기"가 마감된 투표에 대해 "마감됨"을 돌려준다. 투표 화면을 열어 둔 채 마감 시각이 지난 뒤 제출해도 거절된다
- [ ] 마감된 투표 화면은 선택 입력 없이 마감 안내와 결과를 보여준다
- [ ] "투표 하나 보기"의 결과 공개가 스펙 규칙대로다: 운영자이거나, 이 동아리원이 표를 던졌거나, 마감되었으면 결과를 포함하고, 그 외에는 포함하지 않는다
- [ ] 운영자에게는 투표 화면에서 표를 던지지 않았어도 결과가 보인다
- [ ] 마감 경계값(마감 시각 1분 전은 받고, 마감 시각 정각은 거절)과 결과 공개 조합(운영자 / 표 던진 동아리원 / 표 안 던진 동아리원 × 마감 전·후) 테스트가 투표 모듈 경계에서 통과한다
