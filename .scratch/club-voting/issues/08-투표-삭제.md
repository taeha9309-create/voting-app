# 08: 투표 삭제

**What to build:** 운영자가 투표 화면에서 "영구 삭제되며 되돌릴 수 없다"는 확인을 거쳐 투표를 삭제하면, 그 투표와 선택지, 표가 모두 사라지고 목록으로 돌아간다. 삭제된 투표의 링크를 열면 "투표를 찾을 수 없다"는 화면이 나온다. 스펙의 "삭제", User Story 17, 47~49.

**Blocked by:** 03 (투표 만들기, 그리고 투표 화면 보기)

**Status:** ready-for-agent

- [ ] 투표 모듈의 "투표 삭제하기"가 성공, 또는 "투표 없음"을 돌려준다
- [ ] 선택지와 표는 DB 연쇄 삭제로 함께 지워진다
- [ ] 운영자 투표 화면에 삭제 버튼이 있고, 확인 창을 거쳐야 삭제된다. 삭제 후 첫 화면으로 간다
- [ ] 로그인하지 않은 요청이 이 동작을 직접 호출하면 서버에서 거절된다
- [ ] 삭제 후 "투표 하나 보기"와 "표 던지기"가 "찾을 수 없음"을 돌려주는지, 남은 선택지·표가 없는지 테스트가 투표 모듈 경계에서 통과한다
